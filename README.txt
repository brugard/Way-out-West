WAY OUT WEST & STAY OUT WEST I FICKAN
======================================

Ett eget litet schema för hela festivalen, i samma svartvita
affischstil som finns på wayoutwest.se, där du kan markera vilka
konserter som är bäst, bra eller strunt samma.


INSTALLATION
------------

1. Ladda ner filen "schedule.html" till telefonen.

2. Öppna filen i Chrome.
   Om telefonen föreslår att öppna den med Google Docs eller Drive:
   välj Chrome istället. Om inget val dyker upp, öppna Chrome
   manuellt och gå till Nedladdningar (menyn med tre punkter uppe
   till höger), och tryck på filen där.

3. Lägg till på hemskärmen för app-känsla:
   Chrome-meny (tre punkter) -> "Lägg till på startskärm".


ANVÄNDNING
----------

Allt nedan finns även inne i appen - tryck på den lilla i-knappen
uppe till höger i headern.

- Svep vänster/höger, eller använd pilarna i headern, för att bläddra
  mellan sex sidor: torsdag, fredag, lördag, varje dag med både
  Way Out West och Stay Out West.

- Byter du mellan WOW och SOW samma dag hamnar du på samma klockslag
  som du precis tittade på.

- Tryck på en konsert för att växla status:
  neutral -> bra -> bäst -> neutral igen.

- Tryck på notsymbolen i hörnet av ett block för att söka upp
  artisten på Tidal.

- Den rosa knappen "Spellista" öppnar hela Tidal-spellistan för den
  scenen du är på.

- "Spara till fil" längst ner sparar alla dina val i en fil, som
  backup om webbläsaren skulle glömma dem.

- Bakgrundsfärgen visar var på dygnet du är:
  vit = bara WOW igång
  rosa = båda igång samtidigt
  krämvit = bara SOW kvar
